The mental model

Follow one deployment through the system

Click each stage. Do not memorize boxes—understand what responsibility moves from one box to the next.

01

Control plane

microPass decides what should run, records state, and asks Docker to execute workloads. It is not the deployed application itself.

02

State machine

A deployment moves through explicit states. State makes long-running work observable, recoverable, and explainable.

03

Side effects

Git, Docker, networks, and files live outside the database. Good engineering handles partial failure between them.
